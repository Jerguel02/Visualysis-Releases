## 🚀 Features

### 📟 Serial Monitor & Streamer
- **High-Speed Communication**: Optimized interface for communicating with microcontrollers (ESP32, Arduino, STM32).
- **Protocol Decoding**: Built-in support for decoding custom packet formats, including live image streaming from cameras (OVxxxx).
- **Real-time Plotting**: Visualize sensor data with low-latency graphs.

### 🖼️ Image Processing Engine
- **Live Filters**: Apply Computer Vision algorithms (Canny Edge, Thresholding, Morphology) to live video streams.
- **Hardware Acceleration**: Powered by **Rust** and **WebGL** for smooth 60FPS performance.

### 📈 Education Hub
- **50+ Interactive Simulations**: A comprehensive curriculum covering:
  - 📐 **Mathematics**: Calculus, Linear Algebra, Trigonometry.
  - 👁️ **Computer Vision**: FFT, Convolution, Hough Transform, Lens Models.
- **Visual Learning**: Manipulate parameters in real-time to understand complex concepts intuitively.

## 🤝 Usage Guide

1. **Connect Hardware**: Plug in your serial device (ESP32/Arduino).
2. **Select Port**: Navigate to the **Serial Monitor** tab (<kbd>Terminal</kbd> icon) and select your COM port.
3. **Visualize**:
    - Switch to **Education Hub** to explore math models.
    - Switch to **Image Processor** to apply CV filters to the camera stream.
